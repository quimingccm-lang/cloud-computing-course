# Laboratory 01 – Welcome to the Cloud

## Mission Overview

In this laboratory activity, I explored a cloud-based Linux environment using KillerCoda. I learned basic Linux commands, created a new user, gathered system information, organized files and folders, and prepared a GitHub repository to document my work.

## Objectives

- Access a cloud-based Linux environment.
- Learn basic Linux commands.
- Collect system information.
- Organize files and directories.
- Create and manage Markdown files.
- Build a GitHub portfolio for cloud computing activities.

## Activities Performed

- Created a new Linux user.
- Verified the current user, working directory, and hostname.
- Collected system information using Linux commands.
- Created directories and Markdown files.
- Organized the laboratory folder structure.
- Prepared files for upload to GitHub.

## Linux Commands Used

- `adduser`
- `usermod`

- `uname`

- `df`

- `nano`
- `touch`
- `tree`

## Skills Learned

- Basic Linux command-line navigation.
- Managing users and directories.
- Collecting and documenting system information.
- Using Markdown for documentation.
- Organizing files in a GitHub repository.
