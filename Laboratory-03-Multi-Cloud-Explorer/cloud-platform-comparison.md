|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008 |
| Compute Service | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage Service | Amazon S3 | Azure Blob Storage | Cloud Storage |

## 2. Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

AWS offers the broadest range of cloud services among the three major providers. Its large service portfolio covers computing, storage, networking, databases, security, analytics, machine learning, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure best integrates with Microsoft technologies. It is particularly suitable for organizations already using Windows Server, Microsoft 365, Active Directory, and other Microsoft enterprise technologies.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is especially strong in artificial intelligence, machine learning, and Kubernetes. Google Cloud provides extensive data and AI capabilities and operates Google Kubernetes Engine (GKE), a managed Kubernetes service.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Google Cloud Platform because I am interested in artificial intelligence, data analytics, and cloud-native technologies. Google Cloud also provides strong Kubernetes capabilities through Google Kubernetes Engine, making it a good platform for learning modern cloud application development.
