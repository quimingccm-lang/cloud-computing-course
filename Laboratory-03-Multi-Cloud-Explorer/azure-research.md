# Microsoft Azure Research

## 1. Brief Overview

Microsoft Azure is Microsoft's cloud computing platform for building, deploying, and managing applications and services. Azure supports organizations of different sizes and provides infrastructure, platform, data, networking, security, and artificial intelligence services.

## 2. Global Infrastructure

Azure operates a global cloud infrastructure consisting of geographic regions and datacenters around the world. This infrastructure allows organizations to deploy applications closer to their users, meet data residency requirements, and design systems for availability and resilience.

## 3. Cloud Management Console

The Azure portal is a web-based unified console used to create, manage, and monitor Azure resources. Through the portal, users can manage services such as virtual machines, databases, applications, networking resources, and costs.

## 4. Four Core Services

### Azure Virtual Machines

Azure Virtual Machines provide scalable virtual computing resources that allow organizations to run applications and operating systems in the cloud.

### Azure Blob Storage

Azure Blob Storage is an object storage service designed for storing large amounts of unstructured data such as documents, images, videos, backups, and application data.

### Azure Virtual Network

Azure Virtual Network allows organizations to create private networks in Azure and control communication between cloud resources and external networks.

### Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud-based identity and access management service. It helps organizations manage users, applications, devices, and access to resources.

## 5. Three Advantages

1. **Microsoft integration** – Azure integrates closely with Microsoft technologies such as Windows Server, Microsoft 365, and other Microsoft services.
2. **Global infrastructure** – Azure provides a large global infrastructure that supports applications deployed in different geographic locations.
3. **Hybrid and multicloud capabilities** – Azure provides tools that help organizations manage resources across on-premises, edge, and multicloud environments.

## 6. Typical Enterprise Use Cases

Azure can be used by enterprises for application hosting, Windows Server workloads, database systems, business applications, data analytics, artificial intelligence, backup and disaster recovery, and hybrid cloud environments. Organizations can also use Azure to extend existing Microsoft-based infrastructure into the cloud.
