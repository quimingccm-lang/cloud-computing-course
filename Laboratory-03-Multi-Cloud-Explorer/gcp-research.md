# Google Cloud Platform (GCP) Research

## 1. Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is Google's cloud computing platform. It provides cloud infrastructure, computing, storage, databases, networking, data analytics, artificial intelligence, machine learning, and other services that organizations can use to build and scale applications.

## 2. Global Infrastructure

Google Cloud operates a global infrastructure organized into regions and zones. Regions represent geographic areas, while zones are locations within regions where cloud resources can run. This structure helps organizations improve application availability, redundancy, performance, and reliability.

## 3. Cloud Management Console

The Google Cloud console is a web-based graphical interface used to manage Google Cloud projects and resources. Users can use the console to create and manage services, monitor resources, configure permissions, view billing information, and access tools such as Cloud Shell.

## 4. Four Core Services

### Compute Engine

Compute Engine provides configurable virtual machines that allow organizations to run applications and workloads on Google's infrastructure.

### Cloud Storage

Cloud Storage is an object storage service used to store and retrieve data such as files, backups, media, and application data.

### Cloud SQL

Cloud SQL is a fully managed relational database service that supports database engines such as MySQL, PostgreSQL, and SQL Server.

### Google Kubernetes Engine (GKE)

Google Kubernetes Engine is a managed Kubernetes service used to deploy, manage, and scale containerized applications.

## 5. Three Advantages

1. **Strong data and AI capabilities** – Google Cloud provides powerful services for data analytics, artificial intelligence, and machine learning.
2. **Global network** – Google Cloud uses Google's global infrastructure and network to provide reliable and high-performance connectivity.
3. **Kubernetes and container expertise** – Google Cloud provides strong support for Kubernetes and containerized applications through Google Kubernetes Engine.

## 6. Typical Enterprise Use Cases

Google Cloud can be used by enterprises for web and application hosting, data analytics, artificial intelligence and machine learning, database management, containerized applications, global applications, backup, and large-scale data processing. Organizations can combine Google Cloud services to build scalable and highly available systems.
