# Client Recommendations

## Client A – Startup Company

### Recommended Platform: Amazon Web Services (AWS)

AWS is a suitable choice for the startup because it provides a broad range of cloud services and allows the company to scale its resources as the mobile application grows. The startup can begin with relatively small cloud resources and increase capacity as demand increases. AWS also provides services that can support application development, storage, databases, and networking. This makes AWS a flexible option for a startup with limited resources and expectations of rapid growth.

### Recommended Services

- Amazon EC2 – Virtual computing for application workloads
- Amazon S3 – Object storage for application data and files
- Amazon RDS – Managed relational database service
- Amazon VPC – Virtual networking environment


## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the most appropriate choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies and can help the university migrate selected services while maintaining familiar Microsoft-based management and identity systems. The university can gradually move workloads to Azure instead of replacing its entire infrastructure at once. Azure also supports hybrid cloud environments, which can be useful during a gradual migration.

### Recommended Services

- Azure Virtual Machines – Cloud-based Windows Server workloads
- Microsoft Entra ID – Identity and access management
- Azure Virtual Network – Private cloud networking
- Azure Backup – Backup and recovery


## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

Google Cloud is a strong choice for the AI research company because it provides extensive artificial intelligence, machine learning, data analytics, and high-performance computing capabilities. The company can use Google's cloud infrastructure to develop, train, and deploy AI and ML applications. Google Cloud also provides services designed for large-scale data processing and machine learning workloads. These capabilities make it appropriate for a research organization that requires powerful computing resources.

### Recommended Services

- Google Compute Engine – Virtual computing resources
- Vertex AI – AI and machine learning platform
- Google Kubernetes Engine (GKE) – Managed Kubernetes for containerized applications
- Cloud Storage – Storage for datasets and other research files


## Client D – Global E-Commerce Company

### Recommended Platform: Amazon Web Services (AWS)

AWS is a suitable platform for the global e-commerce company because it provides global infrastructure and services that can support highly available and scalable applications. The company can deploy its application across multiple locations and automatically adjust resources based on demand. This is especially useful for an online shopping platform that may experience sudden increases in traffic. AWS also provides services for computing, storage, databases, content delivery, and load balancing.

### Recommended Services

- Amazon EC2 – Scalable application computing
- Elastic Load Balancing – Distributes traffic across application resources
- Amazon S3 – Object storage
- Amazon CloudFront – Content delivery
- Amazon RDS – Managed relational database

## 3. Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | AWS provides a broad range of services and allows startups to scale their infrastructure as their applications grow. |
| Enterprise Organization | AWS | AWS offers a large selection of enterprise cloud services, global infrastructure, security capabilities, and scalability. |
| Microsoft Environment | Microsoft Azure | Azure provides strong integration with Microsoft technologies such as Windows Server, Microsoft 365, and Microsoft Entra ID. |
| AI / Machine Learning | Google Cloud Platform (GCP) | GCP provides strong artificial intelligence, machine learning, data analytics, and high-performance computing capabilities. |
| Kubernetes Deployment | Google Cloud Platform (GCP) | Google Cloud provides Google Kubernetes Engine (GKE), a managed Kubernetes service for deploying and managing containerized applications. |
| Global Web Application | AWS | AWS provides global infrastructure and scalable services that can support highly available web applications serving users in different regions. |
