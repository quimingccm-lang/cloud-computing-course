# Mission Reflection

Completing Mission 3 helped me understand that choosing a cloud provider is not simply about selecting the most popular platform. The cloud platform that impressed me the most was Google Cloud Platform (GCP) because of its strong capabilities in artificial intelligence, machine learning, data analytics, and Kubernetes. I found these technologies especially interesting because they are important for modern cloud-native applications.

AWS, Microsoft Azure, and GCP have many similarities. All three providers offer virtual machines, object storage, networking, identity and access management, databases, and Kubernetes services. They also provide global cloud infrastructure, scalability, security features, and management consoles that allow organizations to manage their cloud resources.

Business requirements have an important influence on cloud platform selection. An organization needs to consider its budget, existing technologies, workload requirements, scalability, security, location, and technical expertise. For example, Azure is a strong choice for an organization that already uses Microsoft technologies, while GCP can be a good choice for AI and machine learning workloads. AWS can be suitable for organizations that need a broad selection of cloud services and scalable infrastructure.

Acting as a Cloud Solutions Consultant taught me that technical decisions should be based on the client's actual needs. Instead of automatically recommending one provider, I learned to analyze the business scenario first and then match the available cloud services to the requirements.

My GitHub Cloud Computing Portfolio has also improved after completing this mission. I added organized documentation for AWS, Azure, and GCP, comparison tables, client recommendations, a decision matrix, Linux investigation results, and supporting screenshots. This makes my portfolio more structured and demonstrates my understanding of cloud computing concepts and practical cloud evaluation.
