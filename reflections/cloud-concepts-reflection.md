# Cloud Computing Concepts Reflection

Cloud computing is an important part of my daily life because I use many online services for communication, creativity, and digital payments. Three cloud services that I regularly use are Messenger, Canva, and GCash. These applications make my daily tasks easier because I can communicate with others, create school projects, and send or receive money anytime as long as I have an internet connection. Before studying cloud computing, I did not realize that these services depend on cloud technology to provide fast, reliable, and convenient access.

Messenger is a **Software as a Service (SaaS)** application because it allows users to send messages, make voice and video calls, and share files through the internet without installing or managing servers. It uses the **Public Cloud** deployment model because it is available to anyone who creates an account.

Canva is also a **Software as a Service (SaaS)** platform because it provides online graphic design tools through a web browser or mobile application. It is hosted on the **Public Cloud**, allowing users to access their designs from different devices with an internet connection. This is especially useful for creating presentations, posters, and school projects.

GCash is another **Software as a Service (SaaS)** application because it offers digital payment, money transfer, and online financial services through the internet. It mainly uses the **Public Cloud** to provide secure and convenient access for millions of users, making everyday transactions faster and more efficient.

Git and GitHub are important in cloud computing because they provide version control. Version control helps developers track changes, restore previous versions of files, and avoid losing important work. GitHub also makes collaboration easier by allowing multiple team members to work on the same project, review changes, and manage updates efficiently. This helps reduce errors, improve teamwork, and keep cloud projects organized.

From this activity, I learned that cloud computing is more than just online storage. It powers many of the applications I use every day and makes them accessible from almost anywhere. I also learned that GitHub is an essential platform for organizing projects, tracking changes, and collaborating with other developers. Understanding these concepts has given me a better appreciation of how cloud technology supports both my studies and everyday life.
